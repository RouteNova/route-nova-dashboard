# RouteNova - Dashboard Administrativo

Plataforma web administrativa de RouteNova desarrollada con React. Permite la gestión de rutas, estudiantes, conductores y transporte escolar, además del monitoreo en tiempo real, visualización de mapas y administración general del sistema.

## Desarrollo

Este proyecto utiliza **React + Vite** para proporcionar un entorno de desarrollo rápido con Hot Module Replacement (HMR) y reglas de ESLint configuradas.

### Instrucciones de inicio rápido

1. Instalar las dependencias:
   ```bash
   npm install
   ```

2. Levantar el servidor de desarrollo local:
   ```bash
   npm run dev
   ```

3. Compilar para producción:
   ```bash
   npm run build
   ```
